# Chapter 9 – The Muscular System Guided Notes

Interactive notes website created from the original Chapter 9 Google Doc. All 11 substantial embedded image assets are included (a 1×1 document layout artifact is omitted). Multiple uses of the same image share one asset. Tables and blank labeling areas remain editable.

Upload `index.html`, `README.md`, and the complete `media` folder to the root of a public GitHub repository. In Settings → Pages, deploy main / (root).

Features include autosaved answers, progress and unanswered-field checks, annotatable diagrams, text label color/size/background, pen, arrows, moving and resizing arrows, undo/redo, editable/deletable labels, clear per picture, full screen labeling, JSON backup, PDF printing with half-inch margins, and Google Docs-compatible HTML export.
